# Security Policy

## Reporting a vulnerability

If you discover a security issue in `acqflo-mcp`, please email **help@acqflo.com** with the subject line `Security: [brief description]`. **Do not file a public GitHub issue** for security reports.

We acknowledge reports within 2 business days and aim to resolve confirmed critical or high-severity issues within 30 days.

When reporting, please include:
- A description of the vulnerability
- Steps to reproduce (or a proof of concept)
- The impact you observed

## Scope

In scope:
- This MCP server (`acqflo-mcp`) and any code in this repository
- The `.mcpb` distribution bundle

Out of scope (report to the respective vendor):
- The AcqFlo application itself — see [acqflo.com/security](https://acqflo.com/security)
- Claude Desktop or the MCP SDK — report to Anthropic
- Third-party dependencies — report upstream

## Safe harbor

We will not pursue legal action against researchers who report vulnerabilities in good faith and follow this policy. Please:
- Use only test accounts you control
- Do not access, modify, or delete data belonging to other AcqFlo customers
- Give us a reasonable opportunity to fix the issue before public disclosure
